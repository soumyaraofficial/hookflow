# Database

## Conventions
- Primary keys: UUID, generated by the application
- Timestamps: TIMESTAMPTZ, handled as UTC (Java `Instant`)
- Enums: stored as strings with CHECK constraints
- Every schema change is a Flyway migration; applied migrations are never edited
- Tenant-owned tables carry `tenant_id`, and every query is tenant-scoped

## Phase 1 tables
tenants 1---N tenant_memberships N---1 users

| Table | Columns | Notes |
|---|---|---|
| tenants | id, name, status, created_at, updated_at | status: ACTIVE / SUSPENDED |
| users | id, email, password_hash, status, created_at, updated_at | unique on lower(email) |
| tenant_memberships | id, tenant_id, user_id, role, status, created_at | unique(tenant_id, user_id); role: ADMIN / MEMBER |
